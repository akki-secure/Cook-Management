# 要件定義書: 材料によるレシピ検索

## 背景・目的

現在のレシピ一覧では、タイトル・説明文のキーワード検索、カテゴリ絞り込み、タグ絞り込みができる。これに加えて「手元にある材料でレシピを探したい」というニーズに応えるため、材料名でレシピを検索できるようにする。

## スコープ

### 含むもの

- レシピ一覧画面に「材料で検索」用のフリーワード入力欄を追加
- 複数の材料名をスペース区切りで指定した場合、指定したすべての材料を含むレシピのみを表示する(AND検索)
- 検索結果一覧には、既存の一覧表示と同様にレシピ画像を表示する(新規のUIは不要。既存の`image_tag recipe.image`表示を検索結果にもそのまま適用する)
- Minitestによる自動テスト追加(モデルのscope、コントローラの絞り込み)

### 含まないもの(対象外)

- 材料名のオートコンプリート・候補一覧からの選択UI(フリーワード入力のみ)
- 材料アイコン画像による視覚的な検索UI
- OR検索(いずれかの材料を含む)への切り替え機能
- 表記ゆれ吸収(「玉ねぎ」と「たまねぎ」の同義語処理など)

## 機能要件

- レシピ一覧画面(`/recipes`)に、既存の`q`(キーワード)・カテゴリ・タグの検索フォームと並べて、材料名検索欄(`ingredients`パラメータ)を追加する
- 入力例: `玉ねぎ 卵` と入力すると、材料に「玉ねぎ」を含み、かつ「卵」も含むレシピだけが一覧に表示される
- 空白(全角・半角どちらも)で複数キーワードに分割する
- 既存の`search_by_keyword`・`in_category`・`tagged_with`スコープと同様に、`Recipe`モデルに`with_ingredients`スコープを追加する
- 既存のキーワード検索・カテゴリ・タグ絞り込みと併用できる(AND条件で組み合わさる)
- 検索フォームの値は既存の`params[:q]`等と同様に、再表示時にも入力欄に保持する

## 非機能要件

- 既存の配色・フォーム構造(`app/views/recipes/index.html.erb`)に沿ったUIにする
- 既存テストスタイル(Minitest, `ActionDispatch::IntegrationTest`)に沿ったテストを追加する
- N+1クエリを避けるため、既存の`includes(:category, :tags, :user, :ratings, :favorites)`に`:ingredients`を追加する
