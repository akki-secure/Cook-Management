# 要件定義書: ユーザーアイコン画像アップロード

## 背景・目的

これまでユーザーアイコンは「シェフ男性/女性」の2択(`avatar_key`、[user-avatar-icon.md](./user-avatar-icon.md)参照)しか選べず、個性を出せなかった。ユーザー自身の画像をアップロードして表示できるようにする。

Godotクライアントは `/api/v1/status` の `avatar_key` を使ってメイン画面にアイコンを表示していたが、今回はWeb版のみのスコープとし、Godot側のアイコン表示機能ごと廃止した。

## スコープ

### 含むもの

- Userに `avatar_image` を Active Storage の添付として追加(`has_one_attached`、`Recipe#image` と同じパターン)
- Web版: 新規登録・プロフィール編集画面で画像をアップロードできる
- Web版: ヘッダーのユーザーメニュー(ログアウト用ドロップダウンのトリガー部分)、マイページにアップロード画像を表示
- 画像未添付時は、ユーザー名の頭文字を使った円形プレースホルダーを表示
- Minitestによる自動テスト更新

### 含まないもの(対象外)

- Godot版でのアイコン表示(廃止。API(`/api/v1/status`)から `avatar_key` を削除し、`main.gd`/`Main.tscn` からアイコン表示ロジック・ノードを削除)
- 画像のリサイズ・バリアント生成(Recipeの画像アップロードと同様、原寸のまま保存・CSSで表示サイズを制御)
- アップロード画像の削除(差し替えのみ。削除UIは対象外)

## 機能要件

- `User#avatar_image` は任意の画像ファイル(`accept: "image/*"`)
- 新規登録画面・プロフィール編集画面: ファイル選択フィールドでアップロード。プロフィール編集画面では既存の添付画像をプレビュー表示
- ヘッダーの「〇〇さん」表示の前にアイコン画像(小、24px、円形)を表示。**ドロップダウンの開閉・ログアウトボタンの構造やStimulusコントローラ(`data-controller="dropdown"`)には変更を加えない**
- マイページの「お名前」欄付近にアイコン画像(中、64px、円形)を表示
- 表示ロジックは `ApplicationHelper#avatar_tag(user, size:)` に集約し、ヘッダー・マイページ両方から呼び出す

## 非機能要件

- 既存の画像アップロードパターン(`Recipe#image`, `app/views/recipes/_form.html.erb`)に沿った実装にする
- 既存テストスタイル(Minitest, `fixture_file_upload`)に沿ったテストを追加・更新する
