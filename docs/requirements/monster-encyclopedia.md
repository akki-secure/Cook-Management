# 要件定義書: モンスター図鑑ページ

## 背景・目的

ガチャ機能で入手できる料理モンスターは、現状マイページ(`/profile`)に名前だけのリスト表示があるのみで、イラスト・レアリティ・特徴の説明文(`sprite_key` / `rarity` / `description`)は一切活用されていない。ガチャを回すモチベーションを高め、「まだ見ぬモンスターを集める」楽しさを提供するため、専用の**モンスター図鑑ページ**を新設する。

先行して作成したプロトタイプ(Claude Artifact「くいしんぼう図鑑」)のデザイン・アニメーション仕様をベースに、Railsアプリ本体へ実装する。

## スコープ

### 含むもの

- ログイン済みユーザー向けの図鑑一覧ページ(モンスターのアイコン画像をグリッド表示)
- 一覧の画像をクリックすると、そのモンスターの詳細ページ(No./名前/特徴/アニメーション)が開く
- 前後のモンスターへ移動できる「前へ/次へ」導線
- 未所持モンスターはシルエット表示にし、名前は「？？？」、説明文は非表示にする
- ナビゲーションへの「モンスター図鑑」リンク追加
- 各モンスターのイラストに、既存プロトタイプと同様の常時ループするアニメーション(バウンス・スイング・跳躍・震え・浮遊・回転跳躍など、モンスターごとに異なる動き)
- Minitestによる自動テスト追加

### 含まないもの(対象外)

- モンスターの新規追加・編集(既存の`db/seeds.rb`運用のまま)
- `rarity`カラムを使ったレア度による絞り込み・ソート機能(現状全モンスターrarity=0のため、表示上は将来拡張の余地としてのみ残す)
- 図鑑の共有・SNS投稿機能
- ログイン不要の公開ページ化
- Godotクライアント側(デスクトップアプリ)の変更

## 利用者フロー

1. ログイン済みユーザーが、ヘッダーの「モンスター図鑑」リンク、またはマイページの「図鑑へ」ボタン(本のアイコン画像)をクリックする
2. 図鑑一覧ページが開き、全モンスターがNo.順にアイコングリッドで並ぶ。所持済みは実イラスト、未所持はシルエットで表示される
3. 所持済みモンスターのアイコンをクリックすると、詳細ページ(`/monsters/:id`)に遷移する
4. 詳細ページでは、No./名前/種別タグ/特徴の説明文が表示され、イラストがアニメーションしながら動き続ける
5. 詳細ページの「前へ」「次へ」で隣のNo.のモンスターに移動できる(未所持ページに来た場合はシルエット+「？？？」+「まだ出会っていない」の案内のみ表示)
6. 一覧ページへ戻る導線がある

## 画面一覧

| 画面 | URL | 説明 |
|---|---|---|
| モンスター図鑑(一覧) | `/monsters` | 全モンスターのアイコングリッド。所持/未所持で見た目が変わる |
| モンスター詳細 | `/monsters/:id` | 1体分の詳細ページ。アニメーション・説明文・前後ナビゲーション |

## 機能要件

### 図鑑一覧ページ(`GET /monsters`)

- `Monster.order(:id)` で全件をNo.順に表示する
- 各モンスターについて、`current_user.monsters.include?(monster)` 相当の判定で所持有無を判定する(N+1を避けるため `current_user.user_monsters.pluck(:monster_id)` 等で事前取得)
- 所持済み: 実イラスト(カラー)+ 名前 + No.
- 未所持: イラストをシルエット化(CSSの`filter: brightness(0) opacity(.55)`等)+ 名前は「？？？」+ No.のみ表示
- グリッドはレスポンシブ(スマホ〜デスクトップ)
- ヘッダー付近に「所持数 X / 全Y体」のカウンター表示

### モンスター詳細ページ(`GET /monsters/:id`)

- 所持済みの場合: No./名前/種別タグ/説明文(`monster.description`)/常時ループアニメーション付きイラスト
- 未所持の場合: No.のみ表示し、名前は「？？？」、イラストはシルエット(アニメーションなし、静止)、説明文の代わりに「まだ出会っていない モンスターだ。ガチャで探してみよう。」を表示
- 「前へ」「次へ」: `Monster.order(:id)`上で隣接するIDへのリンク(先頭/末尾では循環させず、リンクを非表示 or disabled にする)
- 「一覧へ戻る」リンク

### アニメーション仕様

- プロトタイプ(`くいしんぼう図鑑` Artifact)と同じ6種類のCSS keyframesアニメーション(bounce/sway/hop/jiggle/spinhop/floaty)をモンスターごとに割り当てる
- `prefers-reduced-motion: reduce` 環境ではアニメーションを無効化する
- 未所持(シルエット)状態ではアニメーションさせない(静止させ、「未確認」感を出す)

### 画像アセットの扱い

- 現在イラストは `godot-client/assets/monsters/*.png` にのみ存在し、Rails側のアセットパイプラインから参照できない
- Web表示用に `app/assets/images/monsters/` へ同ファイルをコピーし、`image_tag("monsters/#{monster.sprite_key}")` で参照する
- シルエット表示はCSSフィルターで実現し、画像自体は複製しない
- マイページの図鑑ボタン用アイコン `cooking_book.png`(既存モンスターイラストと同じピクセルアート調)も `app/assets/images/` に取り込む

### マイページの図鑑導線

- `cooking_book.png` を `app/assets/images/` に配置し、マイページ(`app/views/users/show.html.erb`)に `link_to image_tag("cooking_book.png", ...), monsters_path` の形でボタン画像として設置する
- ピクセルアート調を保つため `image-rendering: pixelated` を適用する
- ホバー時は、モンスター本体ほど激しくは動かさず、軽く浮き上がる/揺れる程度の控えめなインタラクションを付与する
- ヘッダーnavの文字リンク「モンスター図鑑」(下記)とは別の、マイページ内での視覚的な導線として併存させる

### ナビゲーション

- `app/views/layouts/application.html.erb` のヘッダーnavに、ログイン時のみ「マイページ」と「ログアウト」の間に「モンスター図鑑」リンクを追加する

## ルーティング設計

```ruby
resources :monsters, only: [:index, :show]
```

- `MonstersController` を新設。`before_action :require_login`(既存の`GachaController`と同じ認証パターン)
- `show` アクションで前後モンスターの算出を行う(`Monster.where("id > ?", @monster.id).order(:id).first` 等)

## データ・モデルとの対応

既存スキーマをそのまま利用する(マイグレーション追加なし):

- `monsters.name` / `sprite_key` / `description` → 詳細ページの表示に使用
- `monsters.rarity` → 今回は未使用(将来のレア度表示用に温存)
- `user_monsters` → 所持判定に使用(`user.monsters.pluck(:id)` 等)

## 非機能要件

- 既存の配色トークン(`--primary: #e07a3f` 等、`app/assets/stylesheets/application.css`)をベースにしつつ、図鑑ページ専用のCSSを追加する(プロトタイプの温かみのある配色を踏襲)
- 日本語UIで統一する
- 既存のテストスタイル(Minitest、`ActionDispatch::IntegrationTest`、`sign_in_as`ヘルパー)に沿ったテストを追加する
- N+1クエリを発生させない(一覧ページでの所持判定・画像表示)

## 受け入れ条件(Acceptance Criteria)

- [ ] ログイン済みユーザーがヘッダーの「モンスター図鑑」から一覧ページに到達できる
- [ ] 未ログインで `/monsters` にアクセスするとログイン画面にリダイレクトされる
- [ ] 一覧ページで、所持済みモンスターは実イラスト、未所持はシルエット+「？？？」で表示される
- [ ] 所持済みモンスターのアイコンをクリックすると詳細ページに遷移する
- [ ] 詳細ページでイラストが継続的にアニメーション(踊る/跳ねる等)する
- [ ] 未所持モンスターの詳細ページでは「？？？」表示になり、アニメーションしない
- [ ] 詳細ページの「前へ」「次へ」で隣接するNo.に遷移できる。先頭・末尾では該当ボタンが表示されない
- [ ] 所持数カウンター(X / 全Y体)が一覧ページに表示される
- [ ] マイページに図鑑への導線(本のアイコン画像のボタン)があり、クリックすると一覧ページに遷移する
- [ ] 全自動テストがパスする
