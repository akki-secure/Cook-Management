# 要件定義書: モンスター図鑑(Godotクライアント版)

## 背景・目的

Web版(Rails)には図鑑ページ(`/monsters`, `/monsters/:id`)を実装済み(`docs/requirements/monster-encyclopedia.md`参照)。同じ体験をGodotデスクトップクライアント(`godot-client/`)にも追加してほしいとの依頼を受け、当初のWeb版要件定義書で対象外としていたGodot対応を、別ドキュメントとして今回追加する。

## スコープ

### 含むもの

- Godotクライアントに、全モンスターをNo.順に表示する図鑑一覧画面(未所持はシルエット表示)
- 一覧のアイコンをタップすると開く詳細画面(No./種別タグ/名前/説明文、常時ループするアニメーション)
- 詳細画面の「＜」「＞」による前後モンスターへの移動(先頭・末尾ではdisabled)
- メイン画面(所持モンスター一覧)への「モンスター図鑑」ボタン追加
- Rails API側に、未所持を含む全モンスターを返す新エンドポイント追加(既存`/api/v1/monsters`は変更しない)

### 含まないもの(対象外)

- Godot側のUIテーマ・共通デザインシステムの新規導入(既存同様エンジンデフォルトのまま)
- レアリティ・絞り込み機能
- オフライン時のキャッシュ表示

## 利用者フロー

1. Godotクライアントのメイン画面で「モンスター図鑑」ボタンをタップする
2. 図鑑一覧画面が開き、全モンスターがNo.順にグリッド表示される。所持済みは実イラスト、未所持はシルエット+「？？？」
3. 所持済み・未所持どちらのアイコンをタップしても詳細画面に遷移する(未所持は「まだ出会っていない」旨を表示するため)
4. 詳細画面では、所持済みならNo./種別タグ/名前/説明文とアニメーションするイラストが、未所持ならNo.のみと「？？？」「まだ出会っていないモンスターだ。ガチャで探してみよう。」が表示される
5. 「＜」「＞」で隣のNo.のモンスターへ移動できる
6. 「戻る」でメイン画面、「図鑑一覧へ戻る」で一覧画面に戻れる

## API拡張

- `GET /api/v1/monsters/book`(新規、`Api::V1::MonstersController#book`):`Monster.order(:id)`の全件を、所持有無を示す`owned`フラグ付きで返す。`type_label`/`animation_class`(Web版実装時に`Monster`モデルへ追加済み)も含む
- 既存の`GET /api/v1/monsters`(所持モンスターのみ返す)は変更しない。Godot側の他画面(メインの所持一覧)は引き続きこちらを利用する
- 認証は既存の`Api::V1::BaseController`のBearerトークン方式をそのまま利用

## Godot側の実装方針

- Autoload `MonsterBookState`(`scripts/monster_book_state.gd`)を新設し、一覧で取得したモンスター配列と選択中インデックスを保持する。`change_scene_to_file`にはコンストラクタ引数を渡せないため、シーン間の値渡しに使う
- `scripts/monster_item.gd`の`setup()`に`owned`引数(デフォルト`true`、後方互換)と`tapped`シグナルを追加。既存の所持一覧・ガチャ演出での使用箇所には影響しない
- 新規シーン`MonsterBookScene`(一覧)・`MonsterDetailScene`(詳細)を追加
- アニメーションは既存の`gacha_scene.gd`と同じ`create_tween()`ベースの手法を踏襲し、`set_loops()`で常時ループさせる。Web版CSSの6種(bounce/sway/hop/jiggle/spinhop/floaty)に対応する動きを実装
- 回転を伴うspinhopは、アイコンの`pivot_offset`を中心(`size / 2`)に設定してから回転させる。足元(デフォルトの左上原点)のままだと、Web版のCSS実装で実際に発生した「回転時にキャラクターが名前テキストへはみ出す」不具合を再発するため

## 非機能要件

- 既存のGodotコード規約(タブインデント、`@onready`、シーンごとの`HTTPRequest`ノード)に沿う
- 日本語UIで統一する
